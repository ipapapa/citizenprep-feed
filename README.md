# CitizenPrep answers feed

The live "current answers" feed for the CitizenPrep iOS app (private repo — only
the published Pages site is readable, and it serves public facts only: the names
of current officeholders).

## To update an answer (e.g., after an election)
1. Edit `answers.json` (works from the GitHub app on a phone).
2. Bump the `updated` date.
3. Commit — GitHub Pages republishes automatically within a minute or two.

Every app user is corrected on next launch. No App Store update needed.
