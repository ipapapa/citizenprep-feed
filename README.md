# CitizenPrep answers feed

The live "current answers" feed for the CitizenPrep iOS app. It contains only
public facts — the names of current U.S. officeholders (President, VP, Speaker,
Chief Justice, senators, representatives, governors).

Served via GitHub Pages:
`https://ipapapa.github.io/citizenprep-feed/answers.json`

## To update an answer (e.g., after an election)
1. Edit `answers.json` — works from the GitHub app on a phone.
2. Bump the `updated` date.
3. Commit — GitHub Pages republishes automatically within a minute or two.

Every app user is corrected on their next launch. No App Store update, no
review delay. Officials verified as of **2026-07-07**.
